# Workshop 6 — การเปิด-ปิดหลอดไฟฟ้าโดยการตรวจจับความเข้มแสง (Wokwi + VS Code)

คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏร้อยเอ็ด

## โครงสร้างไฟล์

```
Workshop_6/
├── platformio.ini      ← ตั้งค่าบอร์ดและ framework
├── wokwi.toml          ← บอก Wokwi ว่าเฟิร์มแวร์อยู่ที่ไหน
├── diagram.json        ← วงจรจำลอง (ESP32 + LDR + LED)
├── src/
│   └── main.cpp        ← โค้ดที่ต้องเขียน/แก้ไข
└── README.md
```

## ขั้นตอนใช้งานอย่างย่อ

1. ติดตั้งส่วนขยายใน VS Code: **PlatformIO IDE** และ **Wokwi Simulator**
2. `Ctrl+Shift+P` → `Wokwi: Request a New License` (ถ้ายังไม่เคยขอ)
3. เปิดโฟลเดอร์ `Workshop_6` ด้วย VS Code
4. กด **Build** (✓) ของ PlatformIO หรือ `pio run` รอจนขึ้น `SUCCESS`
5. `Ctrl+Shift+P` → `Wokwi: Start Simulator`
6. คลิกที่เซนเซอร์ LDR ในหน้าจำลอง แล้วเลื่อนแถบ **lux** เพื่อจำลองความสว่าง

## หมายเหตุสำคัญ

* Wokwi ยังไม่รองรับ ESP8266 ใบงานนี้จึงใช้ **ESP32 DevKit V1** แทน
* ADC ของ ESP32 เป็น **12 บิต (0–4095)** ไม่ใช่ 10 บิต (0–1023) แบบ NodeMCU
  ค่าเกณฑ์ 400 ในใบงานเดิมจึงต้องปรับสเกลใหม่ (400 × 4 ≈ 1600)
* ต้องเลี้ยงไฟโมดูล LDR ด้วย **3V3 เท่านั้น** ห้ามใช้ 5V เพราะขา ADC ของ ESP32
  รับแรงดันได้ไม่เกิน 3.3 V
* **ค่าที่อ่านได้จริงต้องวัดเอง** อย่าเชื่อค่าในตารางของคู่มือโดยตรง
  เพราะตารางนั้นอ้างอิงที่ VCC = 5V และ ADC 10 บิต
