# Workshop 8 — การประยุกต์ใช้ IoT กับอุปกรณ์ตรวจจับ (Wokwi + VS Code)

คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏร้อยเอ็ด

ใบงานนี้แบ่งเป็น 2 การทดลอง แยกกันคนละโฟลเดอร์ เพราะ Wokwi ใช้ไฟล์ `diagram.json`
ได้เพียงหนึ่งไฟล์ต่อหนึ่งโปรเจกต์

```
Workshop_8_1/     ตรวจจับการรั่วไหลของแก๊ส (MQ-2 + Buzzer + LED)
Workshop_8_2/     วัดระยะทางด้วยอัลตราโซนิค (HC-SR04)
```

แต่ละโฟลเดอร์มี `platformio.ini`, `wokwi.toml`, `diagram.json` และ `src/main.cpp` ครบในตัว
ให้เปิดทีละโฟลเดอร์ด้วย `File → Open Folder…` แล้ว Build ก่อนสั่ง `Wokwi: Start Simulator`

## หมายเหตุสำคัญ

* Wokwi ยังไม่รองรับ ESP8266 ใบงานนี้จึงใช้ **ESP32 DevKit V1** โดยคงหมายเลข GPIO เดิมไว้
* ADC ของ ESP32 เป็น 12 บิต (0–4095) ค่าเกณฑ์ 300 ของใบงานเดิมจึงปรับเป็น 1200
* MQ-2 ในใบงานนี้เลี้ยงไฟด้วย 3V3 เพื่อไม่ให้แรงดันที่ขา AO เกินพิกัด ADC ของ ESP32
* บนบอร์ดจริง ขา ECHO ของ HC-SR04 ส่งสัญญาณ 5V ต้องผ่านวงจรแบ่งแรงดันก่อนเข้า ESP32
* ฟังก์ชัน `tone()` ใช้ได้กับ ESP32 Arduino core ตั้งแต่รุ่น 2.0.3 ขึ้นไป
  ถ้าคอมไพล์แล้วแจ้งว่าไม่รู้จัก `tone` ให้อัปเดต platform ด้วยคำสั่ง `pio pkg update`
