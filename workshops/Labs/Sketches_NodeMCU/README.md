# ชุดโปรแกรมสำหรับบอร์ด NodeMCU จริง (Arduino IDE)

คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยราชภัฏร้อยเอ็ด

| โฟลเดอร์ | ใบงาน | เนื้อหา |
|---|---|---|
| Workshop_0_Test | ใบงานที่ 0 | โปรแกรมทดสอบบอร์ดและ Serial Monitor |
| Workshop_5 | ใบงานที่ 5 | PIR Sensor ควบคุมรีเลย์และหลอด LED |
| Workshop_6 | ใบงานที่ 6 | LDR ควบคุมการเปิด-ปิดหลอดไฟ |
| Workshop_8_1 | ใบงานที่ 8 ตอนที่ 1 | MQ-2 ตรวจจับแก๊สรั่ว พร้อมบัซเซอร์และ LED |
| Workshop_8_2 | ใบงานที่ 8 ตอนที่ 2 | HC-SR04 วัดระยะทาง |

## วิธีใช้

1. คัดลอกทั้งโฟลเดอร์ไปไว้ใน Documents/Arduino
2. เปิดไฟล์ .ino ด้วย Arduino IDE (ชื่อไฟล์ต้องตรงกับชื่อโฟลเดอร์เสมอ)
3. ตั้งค่า Tools → Board เป็น NodeMCU 1.0 (ESP-12E Module) และ Upload Speed 115200
4. เลือก Port ให้ตรงกับบอร์ดที่เสียบอยู่ แล้วกด Upload
5. เปิด Serial Monitor ตั้งความเร็วเป็น 115200

## ข้อควรระวังด้านแรงดัน

- ขา A0 ของ NodeMCU รับได้ 0-3.3V เท่านั้น ความละเอียด 10 บิต (0-1023)
- สัญญาณ O/P ของ MQ-2 และ ECHO ของ HC-SR04 เป็นระดับ 5V ต้องผ่านวงจรแบ่งแรงดัน 1k/2k ก่อนเสมอ
- ขา D3 (GPIO0), D4 (GPIO2) และ D8 (GPIO15) เป็นขากำหนดค่าเริ่มต้นของระบบ ไม่ควรใช้ขับโหลด
