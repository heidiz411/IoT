## 1. สิ่งที่ต้องเตรียม

| รายการ | หมายเหตุ |
|---|---|
| บอร์ดทดลอง IoT Training Board | มีบล็อก NodeMCU, POWER SUPPLY, LED, RELAY, PIR, LDR, GAS, ULTRASONIC, BUZZER |
| บอร์ด NodeMCU (ESP8266 ESP-12E) | ตรวจดูชิป USB บนบอร์ดว่าเป็น CH340 หรือ CP2102 |
| คอมพิวเตอร์ + อินเทอร์เน็ต | Windows, macOS หรือ Linux |
| **สาย Micro USB ชนิดสายข้อมูล** | ไม่ใช่สายชาร์จอย่างเดียว — ดูข้อควรระวังด้านล่าง |
| สายต่อวงจร (jumper wire) | สำหรับต่อระหว่างบล็อกบนบอร์ดทดลอง |

> ### ⚠️ สายชาร์จกับสายข้อมูลไม่เหมือนกัน
>
> สาเหตุอันดับหนึ่งที่คอมพิวเตอร์มองไม่เห็นบอร์ด คือการใช้สาย Micro USB ที่ต่อเฉพาะขาไฟเลี้ยง
> อาการคือ **ไฟบนบอร์ดติดแต่ไม่ปรากฏพอร์ตในระบบ** ถ้าเจออาการนี้ ให้เปลี่ยนสายเป็นอันดับแรก
> ก่อนจะไปไล่หาสาเหตุอื่น

## 2. ติดตั้ง Arduino IDE

1. เปิดเว็บเบราว์เซอร์ไปที่ <https://www.arduino.cc/en/software>
2. ดาวน์โหลด **Arduino IDE 2.x** ให้ตรงกับระบบปฏิบัติการของเครื่อง
3. ติดตั้งตามขั้นตอนปกติ หากระบบถามสิทธิ์ให้ติดตั้งไดรเวอร์ USB ให้กด **อนุญาตทุกครั้ง**
4. เปิดโปรแกรมครั้งแรก รอให้ดาวน์โหลดส่วนประกอบพื้นฐานจนเสร็จ

## 3. ติดตั้งไดรเวอร์ USB-to-Serial

ดูที่ชิปสี่เหลี่ยมเล็กใกล้พอร์ต USB บนบอร์ด NodeMCU แล้วเลือกติดตั้งไดรเวอร์ให้ตรงรุ่น

| ชิปบนบอร์ด | ชื่อไดรเวอร์ | แหล่งดาวน์โหลด | ชื่อพอร์ตที่จะปรากฏ |
|---|---|---|---|
| CH340 / CH340G | CH341SER | เว็บไซต์ของ WCH (wch-ic.com) | Windows: `COMx`<br>macOS: `/dev/cu.wchusbserial*` |
| CP2102 | CP210x VCP Driver | เว็บไซต์ของ Silicon Labs | Windows: `COMx`<br>macOS: `/dev/cu.SLAB_USBtoUART` |

### ตรวจสอบว่าเครื่องมองเห็นบอร์ดหรือยัง

**Windows** — เปิด Device Manager ดูหัวข้อ `Ports (COM & LPT)` ต้องมีรายการ
`USB-SERIAL CH340` หรือ `Silicon Labs CP210x` ปรากฏ

**macOS / Linux** — เปิด Terminal แล้วพิมพ์

```bash
ls /dev/cu.*          # macOS
ls /dev/ttyUSB*       # Linux
```

ต้องเห็นชื่ออุปกรณ์เพิ่มขึ้นมาหลังเสียบบอร์ด

> **ผู้ใช้ Linux** ถ้าอัปโหลดแล้วขึ้น `Permission denied` ให้เพิ่มสิทธิ์เข้าถึงพอร์ต
> ```bash
> sudo usermod -a -G dialout $USER
> ```
> แล้วออกจากระบบและเข้าใหม่

## 4. เพิ่มชุดบอร์ด ESP8266

1. เปิด Arduino IDE ไปที่เมนู **File → Preferences**
   (บน macOS คือ **Arduino IDE → Settings**)
2. ที่ช่อง **Additional boards manager URLs** วางข้อความต่อไปนี้แล้วกด OK

```
http://arduino.esp8266.com/stable/package_esp8266com_index.json
```

3. ไปที่แถบ **Boards Manager** (ไอคอนรูปบอร์ดทางซ้าย) พิมพ์ค้นหาคำว่า `esp8266`
4. เลือกแพ็กเกจ **esp8266 by ESP8266 Community** แล้วกด **INSTALL** รอจนติดตั้งเสร็จ

> ### ⚠️ ขั้นตอนนี้ใช้อินเทอร์เน็ตปริมาณมากและใช้เวลานาน
>
> แพ็กเกจ ESP8266 มีขนาดหลายร้อยเมกะไบต์ ถ้าติดตั้งพร้อมกันทั้งห้องอาจใช้เวลาเกิน 20 นาที
> **ควรติดตั้งมาก่อนเข้าคาบเรียน** หรือให้ผู้สอนเตรียมโฟลเดอร์แพ็กเกจสำเร็จไว้ให้คัดลอกลง
>
> - Windows: `C:\Users\<user>\AppData\Local\Arduino15\packages\`
> - macOS: `~/Library/Arduino15/packages/`
> - Linux: `~/.arduino15/packages/`

## 5. ตั้งค่าบอร์ดก่อนอัปโหลด

ไปที่เมนู **Tools** แล้วตั้งค่าตามตารางนี้ **ทุกครั้ง** ก่อนอัปโหลดโปรแกรม

| หัวข้อใน Tools | ค่าที่ต้องเลือก |
|---|---|
| Board | **NodeMCU 1.0 (ESP-12E Module)** |
| Upload Speed | 115200 |
| CPU Frequency | 80 MHz |
| Flash Size | 4MB (FS:2MB OTA:~1019KB) |
| Port | พอร์ตที่ปรากฏหลังเสียบบอร์ด เช่น `COM3` หรือ `/dev/cu.wchusbserial1410` |
| Erase Flash | Only Sketch (เลือก All Flash Contents เฉพาะเมื่อบอร์ดมีปัญหา) |

> **ถ้าเมนู Port เป็นสีเทาเลือกไม่ได้** แสดงว่าระบบยังมองไม่เห็นบอร์ด ให้ตรวจสามอย่างตามลำดับ
> 1. เปลี่ยนสาย USB เป็นสายข้อมูล
> 2. ติดตั้งไดรเวอร์ตามหัวข้อ 3 ให้ตรงรุ่นชิป
> 3. เปลี่ยนพอร์ต USB ของคอมพิวเตอร์ แล้วปิด-เปิด Arduino IDE ใหม่

## 6. อัปโหลดโปรแกรมทดสอบ

สร้างไฟล์ใหม่ด้วย **File → New Sketch** แล้วพิมพ์โปรแกรมนี้ บันทึกชื่อ `Workshop_0_Test`
(หรือเปิดไฟล์สำเร็จรูปจากโฟลเดอร์ `Sketches_NodeMCU/Workshop_0_Test/`)

```cpp
int count = 0;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);      // ไฟ LED บนบอร์ด อยู่ที่ขา D4 (GPIO2)
  Serial.begin(115200);
  delay(500);
  Serial.println();
  Serial.println("=================================");
  Serial.println(" NodeMCU พร้อมใช้งาน");
  Serial.print(" ความเร็ว Serial : ");
  Serial.println(115200);
  Serial.println("=================================");
}

void loop() {
  digitalWrite(LED_BUILTIN, LOW);    // ไฟบนบอร์ดเป็น active-LOW จึงติดเมื่อสั่ง LOW
  delay(500);
  digitalWrite(LED_BUILTIN, HIGH);   // ดับ
  delay(500);

  count++;
  Serial.print("ทดสอบครั้งที่ ");
  Serial.println(count);
}
```

### ขั้นตอน

1. กดปุ่ม **Verify** (เครื่องหมายถูก) เพื่อคอมไพล์ — ต้องไม่มีข้อความสีแดง
2. กดปุ่ม **Upload** (ลูกศรชี้ขวา) รอจนขึ้นข้อความ `Hard resetting via RTS pin...`
3. เปิด **Serial Monitor** (ไอคอนแว่นขยายมุมขวาบน) ตั้งความเร็วมุมขวาล่างเป็น **115200 baud**
4. สังเกตว่า LED สีน้ำเงินบนบอร์ดกะพริบทุก 1 วินาที และมีข้อความนับครั้งปรากฏ

### ตารางบันทึกผล

| รายการตรวจสอบ | ผ่าน / ไม่ผ่าน |
|---|---|
| คอมพิวเตอร์มองเห็นพอร์ตของบอร์ด | |
| คอมไพล์โปรแกรมผ่าน | |
| อัปโหลดโปรแกรมสำเร็จ | |
| LED บนบอร์ดกะพริบ | |
| Serial Monitor แสดงข้อความถูกต้อง | |

## 7. ตารางขาสัญญาณและข้อจำกัด

| ชื่อขาบนบอร์ด | GPIO | ใช้ในใบงาน | ข้อควรระวัง |
|---|---|---|---|
| D0 | 16 | ใบงาน 5 (LED), ใบงาน 8.1 (LED) | ไม่รองรับ interrupt และ PWM |
| D1 | 5 | ใบงาน 8.1 (บัซเซอร์), ใบงาน 8.2 (TRIG) | ใช้งานทั่วไปได้ปลอดภัย |
| D2 | 4 | ใบงาน 8.2 (ECHO) | ใช้งานทั่วไปได้ปลอดภัย |
| D3 | 0 | ไม่ใช้ | ถ้าเป็น LOW ขณะบูต บอร์ดจะเข้าโหมดโปรแกรม |
| D4 | 2 | ไฟ LED บนบอร์ด | ต้องเป็น HIGH ขณะบูต, LED เป็น **active-LOW** |
| D6 | 12 | ใบงาน 5 (ขา IN ของรีเลย์) | ใช้งานทั่วไปได้ปลอดภัย |
| D7 | 13 | ใบงาน 5 (PIR), ใบงาน 6 (LED) | ใช้งานทั่วไปได้ปลอดภัย |
| D8 | 15 | ไม่ใช้ | ต้องเป็น LOW ขณะบูต ห้ามต่อโหลดที่ดึงขาขึ้น |
| A0 | — | ใบงาน 6 (LDR), ใบงาน 8.1 (MQ-2) | รับได้ **0–3.3V เท่านั้น** ความละเอียด 10 บิต (0–1023) |

## 8. ข้อควรระวังด้านแรงดัน

> ### 🔴 อ่านก่อนต่อวงจรใบงานที่ 8 ทุกครั้ง
>
> ขา A0 ของ NodeMCU รับแรงดันได้สูงสุด **3.3 โวลต์**
> ส่วนโมดูล **MQ-2** และ **HC-SR04** ทำงานที่ระดับ **5 โวลต์**
>
> สัญญาณจาก **ขา O/P ของ MQ-2** และ **ขา ECHO ของ HC-SR04**
> ต้องผ่านวงจรแบ่งแรงดันก่อนเสมอ หากต่อตรงจะทำให้ขาสัญญาณหรือทั้งบอร์ดเสียหายถาวร

### วงจรแบ่งแรงดันอย่างง่าย

```
สัญญาณ 5V ──[ 1 kΩ ]──┬── จุดวัด (ประมาณ 3.3V) ──> NodeMCU
                       │
                    [ 2 kΩ ]
                       │
                      GND
```

คำนวณจาก `5 × 2 ÷ (1 + 2) = 3.33 V` ซึ่งอยู่ในพิกัดที่ NodeMCU รับได้พอดี

**ก่อนเสียบสาย USB** ให้ใช้มัลติมิเตอร์วัดแรงดันที่จุดวัดก่อน ต้องไม่เกิน 3.3 โวลต์
จึงจะต่อเข้ากับขา A0 หรือขา D2 ได้ และให้ผู้สอนตรวจวงจรอีกครั้งก่อนจ่ายไฟ

**ส่วนขา TRIG ของ HC-SR04** เป็นอินพุตของโมดูล รับสัญญาณ 3.3V จาก NodeMCU ได้โดยตรง ไม่ต้องแบ่งแรงดัน
เช่นเดียวกับ **ขา O/P ของ PIR** ที่ส่งสัญญาณ 3.3V TTL อยู่แล้ว

## 9. ความปลอดภัยในการปฏิบัติงาน

1. **ถอดสาย USB ออกทุกครั้ง** ก่อนต่อหรือย้ายสายวงจร ห้ามต่อสายขณะบอร์ดมีไฟเลี้ยง
2. ตรวจสอบขั้วบวก-ลบและตำแหน่งขาให้ถูกต้องก่อนจ่ายไฟทุกครั้ง
3. **ห้ามต่อขา 3V3 เข้ากับจุด +5VDC** และห้ามลัดวงจรระหว่างไฟเลี้ยงกับกราวด์
4. ให้ผู้สอนตรวจวงจรก่อนจ่ายไฟทุกครั้งในการทดลองที่มีรีเลย์
5. **ห้ามต่อโหลดไฟฟ้ากระแสสลับ 220 โวลต์** เข้ากับหน้าสัมผัสรีเลย์ในชั้นเรียน ให้ใช้โหลดไฟตรงแรงดันต่ำแทน
6. โมดูล MQ-2 จะร้อนขณะทำงานเพราะมีฮีทเตอร์ภายใน **ห้ามสัมผัสโดยตรงและห้ามทดสอบด้วยเปลวไฟ**
   ทดสอบด้วยการกดก้านไฟแช็กโดยไม่จุดไฟเท่านั้น ในบริเวณที่อากาศถ่ายเท
7. หากได้กลิ่นไหม้ ควันขึ้น หรือบอร์ดร้อนผิดปกติ **ให้ถอดสาย USB ทันที** แล้วแจ้งผู้สอน

## 10. ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | แนวทางแก้ไข |
|---|---|---|
| เมนู Port เลือกไม่ได้ / ไม่เห็นพอร์ต | ใช้สายชาร์จ หรือยังไม่ได้ติดตั้งไดรเวอร์ | เปลี่ยนเป็นสายข้อมูล แล้วติดตั้งไดรเวอร์ CH340 หรือ CP210x ให้ตรงรุ่น |
| `espcomm_open failed` / `Failed to connect` | บอร์ดไม่เข้าโหมดโปรแกรม หรือพอร์ตถูกโปรแกรมอื่นใช้อยู่ | ปิด Serial Monitor แล้วอัปโหลดใหม่ ถ้ายังไม่ได้ให้กดปุ่ม FLASH ค้างไว้แล้วแตะ RST หนึ่งครั้ง |
| Serial Monitor เป็นอักขระอ่านไม่ออก | ความเร็ว baud ไม่ตรงกับที่ตั้งในโปรแกรม | ตั้ง Serial Monitor เป็น 115200 ให้ตรงกับ `Serial.begin()` |
| บอร์ดรีสตาร์ตเองซ้ำ ๆ / ขึ้น `rst cause` | กระแสไฟไม่พอ หรือขา strapping ถูกดึงผิดค่า | เปลี่ยนพอร์ต USB ที่จ่ายไฟดีกว่า และเลี่ยงการใช้ขา D3 / D8 ขับโหลด |
| คอมไพล์ไม่ผ่าน ไม่รู้จัก `D0` หรือ `D7` | เลือกบอร์ดผิดรุ่น (เช่น Generic ESP8266) | ตั้ง Board เป็น **NodeMCU 1.0 (ESP-12E Module)** |
| อัปโหลดแล้วโปรแกรมเดิมยังทำงาน | อัปโหลดลงบอร์ดคนละตัวหรือคนละพอร์ต | ตรวจ Tools → Port ให้ตรงกับบอร์ดที่เสียบอยู่ |
| เซนเซอร์ไม่ตอบสนองเลย | **ลืมต่อกราวด์ร่วม** (สาเหตุอันดับหนึ่ง) | ตรวจว่ากราวด์ของทุกบล็อกและ NodeMCU ต่อถึงกันหมด |
| ค่าแอนะล็อกแกว่งหรือลอย | กราวด์ไม่ร่วมกัน หรือสายหลวม | กดสายให้แน่น ใช้สายสั้นลง และเฉลี่ยค่าจากการอ่านหลายครั้ง |

### ลำดับการไล่ปัญหาอย่างรวดเร็ว

```
ไม่เห็นพอร์ต      → เปลี่ยนสาย USB → ติดตั้งไดรเวอร์ → เปลี่ยนพอร์ต USB
อัปโหลดไม่ผ่าน    → ปิด Serial Monitor → ตรวจ Board → FLASH + RST
Serial เพี้ยน     → ตั้ง 115200
เซนเซอร์ไม่ทำงาน  → ตรวจกราวด์ร่วมก่อนเสมอ → แล้วจึงตรวจขาสัญญาณ
บอร์ดรีสตาร์ตเอง  → จ่ายไฟจากอะแดปเตอร์ภายนอกแทนไฟจาก USB
```
