# คู่มือการติดตั้งและตั้งค่า ESP32 NodeMCU สำหรับ Windows 11 เพื่อใช้งานกับ VS Code

เอกสารนี้จะแนะนำขั้นตอนการเตรียมความพร้อมและการใช้งานบอร์ด **ESP32 NodeMCU** ร่วมกับ **Visual Studio Code (VS Code)** และ **PlatformIO** บนระบบปฏิบัติการ Windows 11 ตั้งแต่การติดตั้งไปจนถึงการอัปโหลดโค้ด

---

## สิ่งที่ต้องเตรียม (Prerequisites)
1. **บอร์ด ESP32 NodeMCU** (เช่น ESP32 DevKit V1, NodeMCU-32S เป็นต้น)
2. **สาย USB** (Micro USB หรือ USB-C ขึ้นอยู่กับบอร์ดของคุณ) **ข้อควรระวัง:** ต้องแน่ใจว่าเป็นสายที่สามารถรับส่งข้อมูลได้ (Data Cable) ไม่ใช่สายชาร์จไฟเพียงอย่างเดียว
3. คอมพิวเตอร์ที่ใช้ระบบปฏิบัติการ **Windows 11**

---

## ขั้นตอนที่ 1: การติดตั้ง Driver สำหรับบอร์ด ESP32
บอร์ด ESP32 ส่วนใหญ่ใช้ชิปแปลงสัญญาณ USB to UART ซึ่งมักจะเป็นชิป **CP210x** หรือ **CH34x** หากเสียบสาย USB แล้ว Windows ไม่รู้จักอุปกรณ์ ให้ดำเนินการดังนี้:

1. เสียบสาย USB เข้ากับบอร์ด ESP32 และคอมพิวเตอร์
2. เปิด **Device Manager** ใน Windows 11 (คลิกขวาที่ปุ่ม Start -> Device Manager)
3. ไปที่หัวข้อ **Ports (COM & LPT)** สังเกตดูว่ามีพอร์ต COM ใหม่เพิ่มขึ้นมาหรือไม่ (เช่น `Silicon Labs CP210x USB to UART Bridge (COM3)` หรือ `USB-SERIAL CH340 (COM4)`)
4. หากมีเครื่องหมายตกใจสีเหลือง หรืออยู่ในหมวด Other devices ให้ดาวน์โหลดและติดตั้ง Driver:
   - **CP210x:** ค้นหาและดาวน์โหลด "CP210x USB to UART Bridge VCP Drivers"
   - **CH34x:** ค้นหาและดาวน์โหลด "CH340 Drivers for Windows"
5. เมื่อติดตั้งเสร็จ ให้จำหมายเลข **COM Port** ไว้ (เช่น COM3)

---

## ขั้นตอนที่ 2: ติดตั้ง VS Code และ PlatformIO Extension
เราจะใช้ PlatformIO ซึ่งเป็น Extension บน VS Code ที่ออกแบบมาเพื่อการพัฒนา IoT และไมโครคอนโทรลเลอร์โดยเฉพาะ

1. ดาวน์โหลดและติดตั้ง **Visual Studio Code** จาก [code.visualstudio.com](https://code.visualstudio.com/)
2. เปิดโปรแกรม VS Code
3. ไปที่เมนู **Extensions** (ไอคอนรูปกล่องสี่เหลี่ยมที่แถบเมนูด้านซ้าย หรือกด `Ctrl+Shift+X`)
4. พิมพ์ค้นหาคำว่า `PlatformIO IDE`
5. กดปุ่ม **Install**
6. รอจนกว่า PlatformIO จะติดตั้งเสร็จ (อาจใช้เวลาสักครู่ในการดาวน์โหลด Core Packages ครั้งแรก) เมื่อเสร็จสิ้นจะมีไอคอนรูป "หน้าเอเลี่ยน" โผล่ขึ้นมาที่แถบด้านซ้าย

---

## ขั้นตอนที่ 3: การสร้างโปรเจกต์ใหม่
1. คลิกที่ไอคอน **PlatformIO** (หน้าเอเลี่ยน) ที่แถบด้านซ้าย
2. ในเมนู Quick Access ให้คลิกที่ **PIO Home** -> **Open**
3. คลิกปุ่ม **+ New Project**
4. ตั้งค่าโปรเจกต์ดังนี้:
   - **Name:** ชื่อโปรเจกต์ (เช่น `ESP32_Blink`)
   - **Board:** ค้นหาและเลือกรุ่นบอร์ดของคุณ (หากไม่ทราบรุ่นแน่ชัด ให้เลือก `Espressif ESP32 Dev Module`)
   - **Framework:** เลือก `Arduino`
   - **Location:** ใช้ค่าเริ่มต้น (Use default location) หรือกำหนดโฟลเดอร์เอง
5. คลิกปุ่ม **Finish** (หมายเหตุ: การสร้างโปรเจกต์ครั้งแรกจะใช้เวลานานพอสมควร เนื่องจากระบบต้องดาวน์โหลด Toolchain สำหรับ ESP32)

---

## ขั้นตอนที่ 4: การตั้งค่า platformio.ini และเขียนโค้ด
1. ในหน้าต่าง Explorer ของ VS Code (ด้านซ้ายมือ) ให้มองหาไฟล์ชื่อ `platformio.ini` เปิดไฟล์นี้ขึ้นมา
2. เพิ่มบรรทัด `monitor_speed = 115200` เข้าไป เพื่อตั้งค่าความเร็วของ Serial Monitor ให้ตรงกับโค้ดที่เราจะเขียน
   ```ini
   [env:esp32dev]
   platform = espressif32
   board = esp32dev
   framework = arduino
   monitor_speed = 115200
   ```

3. ไปที่โฟลเดอร์ `src` แล้วเปิดไฟล์ `main.cpp`
4. ลบโค้ดเดิมออกทั้งหมด และคัดลอกโค้ดทดสอบไฟกะพริบ (Blink) นี้ไปวาง:

   ```cpp
   #include <Arduino.h>

   #define LED_PIN 2 // ขาพินสำหรับ LED บนบอร์ด ESP32 ส่วนใหญ่

   void setup() {
       Serial.begin(115200);      // เริ่มต้นการเชื่อมต่อ Serial
       pinMode(LED_PIN, OUTPUT);  // ตั้งค่าพิน LED เป็น Output
       Serial.println("ESP32 Started!");
   }

   void loop() {
       digitalWrite(LED_PIN, HIGH); // เปิดไฟ LED
       Serial.println("LED ON");
       delay(1000);                 // รอ 1 วินาที
       
       digitalWrite(LED_PIN, LOW);  // ปิดไฟ LED
       Serial.println("LED OFF");
       delay(1000);                 // รอ 1 วินาที
   }
   ```

## ขั้นตอนที่ 5: การคอมไพล์และอัปโหลดโค้ด
สังเกตที่ **แถบสีฟ้าด้านล่างสุด (Status Bar)** ของหน้าต่าง VS Code จะมีไอคอนเครื่องมือสำหรับ PlatformIO

1. **คอมไพล์ (Build):** คลิกที่ไอคอน **เครื่องหมายถูก (✓)** ระบบจะทำการตรวจสอบและคอมไพล์โค้ด หากไม่มีข้อผิดพลาดจะขึ้นข้อความ `SUCCESS`
2. **อัปโหลด (Upload):** 
   - เชื่อมต่อบอร์ด ESP32 ผ่านสาย USB
   - คลิกที่ไอคอน **ลูกศรชี้ขวา (→)**
   - รอจนกระทั่งแถบ Terminal ด้านล่างแสดงความคืบหน้าเป็นเปอร์เซ็นต์

> **💡 การแก้ปัญหาอัปโหลดไม่ผ่าน (Connecting... แล้วค้าง):**
> หากระหว่างอัปโหลดเกิดข้อความ `Connecting...` ค้างอยู่ ให้คุณ**กดปุ่ม BOOT บนบอร์ด ESP32 ค้างไว้** จนกว่าจะเริ่มกระบวนการอัปโหลด (ขึ้นเปอร์เซ็นต์) แล้วจึงปล่อยนิ้ว

---

## ขั้นตอนที่ 6: การดูผลลัพธ์บน Serial Monitor
เพื่อดูข้อความที่ ESP32 ส่งกลับมา (เช่นคำว่า "LED ON" และ "LED OFF")

1. คลิกที่ไอคอน **ปลั๊กไฟ (Serial Monitor)** บนแถบ Status Bar ด้านล่าง
2. Terminal จะเปิดขึ้นมาและแสดงผลลัพธ์การทำงานแบบเรียลไทม์
3. หากแสดงผลเป็นภาษาต่างดาว ให้ตรวจสอบว่าตั้งค่า `monitor_speed` ใน `platformio.ini` เป็น `115200` และในโค้ด `Serial.begin(115200)` ตรงกันหรือไม่
