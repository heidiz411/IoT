## 🧭 คำอธิบายรายวิชา

ศึกษาหลักการของอินเทอร์เน็ตทุกสรรพสิ่ง เทคโนโลยีสำหรับอินเทอร์เน็ตทุกสรรพสิ่ง เทคโนโลยีการสื่อสารทั้งแบบใช้สายและไร้สาย เครือข่ายเซนเซอร์ การแลกเปลี่ยนข้อมูลระหว่างระบบปฏิบัติการแบบต่าง ๆ เทคโนโลยีที่ช่วยให้สรรพสิ่งประมวลผลข้อมูลของตนเองได้ และกรณีศึกษาแอปพลิเคชันเกี่ยวกับอินเทอร์เน็ตทุกสรรพสิ่งที่มีอยู่จริงในปัจจุบัน

## 🎯 จุดมุ่งหมายของรายวิชา

รายวิชานี้มุ่งพัฒนาให้นักศึกษามีความรู้ ความเข้าใจ และทักษะปฏิบัติด้าน Internet of Things โดยสามารถ

1. อธิบายความหมาย ความสำคัญ องค์ประกอบ และสถาปัตยกรรมของระบบ IoT ได้
2. เลือกใช้เครื่องมือ อุปกรณ์ เซนเซอร์ ไมโครคอนโทรลเลอร์ และเทคโนโลยีการสื่อสารที่เหมาะสมกับงาน IoT ได้
3. วิเคราะห์ ออกแบบ และพัฒนาระบบต้นแบบ IoT ขนาดเล็กที่ตอบโจทย์การใช้งานจริงได้
4. ประยุกต์ใช้แนวคิดเครือข่ายเซนเซอร์ การสื่อสารข้อมูล คลาวด์ และ Edge Computing ในระบบ IoT ได้
5. ทำงานร่วมกันเป็นทีม แบ่งบทบาทความรับผิดชอบ และนำเสนอผลงานโครงงาน IoT ได้อย่างเหมาะสม
6. ตระหนักถึงความปลอดภัย ความเป็นส่วนตัว จริยธรรม และจรรยาบรรณในการพัฒนาระบบ IoT

## 🗓️ แผนการสอน 16 สัปดาห์

| สัปดาห์ | หัวข้อหลัก | กิจกรรมเด่น |
|---:|---|---|
| 1 | แนะนำรายวิชา แนวทางการเรียน เกณฑ์การประเมิน และเตรียมเครื่องมือพัฒนา IoT | ติดตั้ง Arduino IDE/เครื่องมือที่จำเป็น ทดลองรันตัวอย่างเบื้องต้น |
| 2 | บทนำสู่อินเทอร์เน็ตในทุกสรรพสิ่ง | วิเคราะห์องค์ประกอบ IoT และระดมสมองอุปกรณ์ IoT รอบตัว |
| 3 | เทคโนโลยีอุปกรณ์สำหรับ IoT | ทดลองบอร์ด Arduino/NodeMCU/ESP32 และเซนเซอร์พื้นฐาน |
| 4 | การสื่อสารข้อมูลแบบใช้สายในระบบ IoT | ทดลอง Serial Communication, UART, I²C/SPI และแนวคิด Ethernet |
| 5 | การสื่อสารข้อมูลแบบไร้สายสำหรับ IoT | วิเคราะห์ Wi-Fi, Bluetooth/BLE, Zigbee, LoRaWAN, NB-IoT และการเลือกใช้ให้เหมาะกับโจทย์ |
| 6 | การแลกเปลี่ยนข้อมูลและโปรโตคอล IoT | ทดลองแนวคิด HTTP/REST, MQTT, CoAP, JSON/XML และ Publish-Subscribe |
| 7 | เครือข่ายเซนเซอร์และการรวมระบบ IoT | ออกแบบเครือข่ายเซนเซอร์สำหรับสถานการณ์จำลอง เช่น เกษตรอัจฉริยะ/Smart Campus |
| 8 | สอบกลางภาค และบทนำ Edge Computing | สอบทฤษฎี/ปฏิบัติครอบคลุมสัปดาห์ 1-7 และเรียนแนวคิด Edge/Fog Computing |
| 9 | Edge Computing สำหรับ IoT | วิเคราะห์ Edge vs Cloud และทดลองประมวลผลข้อมูลเซนเซอร์เบื้องต้นที่อุปกรณ์ |
| 10 | ความปลอดภัยและจริยธรรมในระบบ IoT | อภิปราย Mirai Botnet, Privacy, TLS, Firmware Update และจริยธรรมการเก็บข้อมูล |
| 11 | กรณีศึกษา IoT ด้านบ้านและสุขภาพ | วิเคราะห์ Smart Home, Wearables และความท้าทายด้าน Interoperability |
| 12 | กรณีศึกษา IoT ด้านเมืองและอุตสาหกรรม | วิเคราะห์ Smart City, Industrial IoT และ Predictive Maintenance |
| 13 | โครงงาน IoT ครั้งที่ 1: วางแผนและออกแบบ | ตั้งกลุ่ม เลือกหัวข้อ เขียน Project Proposal และออกแบบ Block Diagram |
| 14 | โครงงาน IoT ครั้งที่ 2: พัฒนาต้นแบบ | ประกอบอุปกรณ์ เขียนโปรแกรม ทดสอบระบบ และแก้ไขปัญหาร่วมกัน |
| 15 | โครงงาน IoT ครั้งที่ 3: นำเสนอและสรุปบทเรียน | สาธิตระบบต้นแบบ ตอบคำถาม รับข้อเสนอแนะ และสรุปแนวทางต่อยอด |
| 16 | สอบปลายภาค | สอบข้อเขียน/ปฏิบัติครอบคลุมเนื้อหาทั้งภาคการศึกษา |

## 🧪 กิจกรรมการเรียนรู้แบบปฏิบัติ

รายวิชาเน้นการเรียนรู้จากการลงมือทำจริง ผ่านกิจกรรมต่อไปนี้

- **Lab-based Learning**: ทดลองต่อวงจร อ่านค่าเซนเซอร์ ควบคุม Actuator และรับส่งข้อมูล
- **Problem-based Learning**: วิเคราะห์โจทย์ IoT จากสถานการณ์จริง เช่น บ้านอัจฉริยะ เมืองอัจฉริยะ และเกษตรอัจฉริยะ
- **Team-based Learning**: ทำงานกลุ่ม แบ่งบทบาท เช่น Hardware, Software, Network/Cloud, Documentation และ Presenter
- **Project-based Learning**: ออกแบบและพัฒนาระบบต้นแบบ IoT พร้อมนำเสนอผลการทำงาน
- **Ethics Discussion**: วิเคราะห์ประเด็นความปลอดภัย ความเป็นส่วนตัว และจริยธรรมของระบบ IoT

## 🤝 การทำงานเป็นทีม

- แบ่งงานอย่างเป็นธรรม และระบุ Contribution ของสมาชิกแต่ละคน
- เคารพความคิดเห็นของเพื่อนร่วมทีม และแก้ปัญหาด้วยเหตุผลเชิงวิชาการ

## 🚀 โครงงาน IoT

### เป้าหมายของโครงงาน

ให้นักศึกษาออกแบบและพัฒนา **ระบบต้นแบบ IoT ขนาดเล็ก** ที่สามารถรับข้อมูลจากเซนเซอร์ ประมวลผลหรือส่งข้อมูลผ่านเครือข่าย และแสดงผล/ควบคุมการทำงานได้อย่างเหมาะสม

### ตัวอย่างหัวข้อโครงงาน

- 🌱 ระบบรดน้ำต้นไม้อัตโนมัติด้วยเซนเซอร์ความชื้นดิน
- 🏠 ระบบควบคุมไฟฟ้าในบ้านผ่าน Wi-Fi
- 🌡️ ระบบตรวจวัดอุณหภูมิและความชื้นพร้อม Dashboard
- ⚡ ระบบติดตามการใช้พลังงานไฟฟ้าเบื้องต้น
- 🚪 ระบบแจ้งเตือนการเปิด-ปิดประตูผ่านเครือข่าย
- 🏫 ระบบตรวจวัดสภาพแวดล้อมภายในห้องเรียนหรืออาคาร

## ✅ ผลลัพธ์ที่คาดหวังเมื่อสิ้นสุดรายวิชา

- อธิบายแนวคิด สถาปัตยกรรม และองค์ประกอบของระบบ IoT ได้

- พัฒนาระบบต้นแบบ IoT เป็นทีม พร้อมสาธิตและนำเสนอผลงานได้
- ใช้ GitHub เพื่อจัดเก็บผลงาน โค้ด เอกสาร และรายงานโครงงานอย่างเป็นระบบได้
